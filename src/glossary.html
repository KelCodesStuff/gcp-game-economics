Technical & Financial Glossary

Definitions of core metrics, systems, infrastructure vectors, and cloud economics parameters.

Player & Concurrency Metrics

DAU (Daily Active Users)

The total number of unique players who log into and interact with the game within a 24-hour period.

CCU (Concurrent Users)

The number of players actively connected to the game servers at any single moment.

Peak CCU

The maximum simultaneous online player count during peak gaming hours (typically local evening hours).

CCU / DAU Ratio

The percentage of daily active users online simultaneously during peak hours (industry standard typically ranges between $5\%$ and $20\%$).

ARPU (Average Revenue Per User)

Total monthly revenue divided by total active users, used to determine whether infrastructure spending per user remains profitable.

Compute & Orchestration

vCPU (Virtual Central Processing Unit)

A unit of cloud compute capacity equivalent to one physical execution thread on a multithreaded cloud server processor.

RAM (Random Access Memory)

System memory required by game server binaries to maintain active map state, spatial physics entities, and connected player structures.

GKE (Google Kubernetes Engine)

GCP’s managed Kubernetes service, used to deploy, auto-scale, and manage containerized game server workloads.

Agones

An open-source, Kubernetes-native game server management framework designed to host, scale, and manage dedicated game server pods in real time.

Compute Density ($\text{CCU / vCPU}$)

The number of concurrent player connections a single vCPU core can simulate simultaneously at the target tick rate.

CUD (Committed Use Discount)

GCP pricing discounts (up to $50\%$) granted when committing to a minimum baseline of resource consumption for a 1- or 3-year term.

Networking & CDN

Tick Rate ($\text{Hz}$)

The frequency at which a dedicated game server updates the simulation state per second (e.g., $60\text{ Hz} = 60$ updates per second). Higher tick rates demand more compute and produce greater network bandwidth.

Bandwidth Footprint ($\text{KB/s}$)

The continuous throughput required per active player connection to synchronize inputs, positions, and game states.

Gameplay Network Egress

Outbound network data transferred from GCP game servers to players' devices during active gameplay.

Premium Network Tier

Google Cloud's low-latency network infrastructure that routes player traffic over Google's global private fiber network rather than the public internet.

CDN (Content Delivery Network)

A distributed network of edge caching servers used to distribute game client patches, shaders, and updates to players with high bandwidth and low latency.

Patch CDN Egress

The outbound data volume transferred when distributing game client updates, patch binaries, and assets to players from GCP Cloud CDN edge caches.

Database & Persistence

Cloud Spanner

GCP’s enterprise-grade, globally distributed, ACID-compliant relational database service built for high-scale global game backends (inventories, currencies, profile progression).

AlloyDB

GCP’s fully managed, PostgreSQL-compatible relational database service optimized for high-throughput transactional and analytical workloads.

Memorystore (Redis)

An in-memory cache service used for sub-millisecond retrieval of session states, matchmaking queues, and leaderboards.

ACID Compliance

Database properties (Atomicity, Consistency, Isolation, Durability) ensuring that financial and inventory transactions (such as item trades or store purchases) are processed reliably without duplication or corruption.

Database & Persistence Tier

The unified data storage layer (combining relational databases like Cloud Spanner or AlloyDB and caching systems like Memorystore) that handles user state, transaction stability, and game progress.

Unit Economics & Financial Metrics

Total Monthly Spend

The total estimated monthly operational cost encompassing compute, network egress, CDN patching, and database infrastructure on GCP.

Cost per DAU

Total monthly infrastructure cost divided by total DAU, measuring infrastructure overhead relative to the total player base.

Cost per Peak CCU

Total monthly infrastructure cost divided by maximum concurrent capacity, measuring infrastructure efficiency under peak traffic loads.

Infra Break-Even ARPU

The average monthly revenue per active user required to exactly cover the game's hosting and infrastructure costs. Calculated as Total Monthly Spend divided by DAU.

Target Profitable ARPU

The average monthly revenue per active user required to keep infrastructure costs within a healthy target budget share (typically 10% to 15% of total revenue), ensuring overall business profitability.

Key Mathematical Equations

Concurrency (Peak CCU)

Calculated by scaling the Daily Active Users (DAU) by the Peak CCU Ratio, representing the highest concurrent player load during peak operational hours:

$$\text{Peak CCU} = \text{DAU} \times \text{ccuRatio}$$

Compute Fleet Cost (GKE / Agones Nodes)

Calculated using GCP Compute Engine baseline node pricing ($\$0.0475$ per vCPU-hour across $730$ average monthly hours):

$$\text{Raw Compute Cost} = \left(\frac{\text{Peak CCU}}{\text{Density}}\right) \times 0.0475 \times 730$$
$$\text{Compute Cost} = \text{Raw Compute Cost} \times (1 - \text{CUD Discount})$$

Gameplay Network Egress Cost

Calculated by converting active player gameplay bandwidth in KB/s to GB/hr, scaling over player playtime, and applying GCP's premium network egress list rate of $\$0.08$ per GB:

$$\text{GB / Hr / User} = \frac{\text{Bandwidth (KB/s)} \times 3600}{1024 \times 1024}$$
$$\text{Monthly Gameplay Egress (GB)} = \text{Peak CCU} \times \text{GB / Hr / User} \times \text{Daily Playtime Hours} \times 30.4$$
$$\text{Egress Cost} = \text{Monthly Gameplay Egress (GB)} \times \$0.08$$

Patch CDN Distribution Cost

Calculated based on total monthly client patches and content updates delivered to the player base (DAU), priced at the standard GCP Cloud CDN distribution rate of $\$0.04$ per GB:

$$\text{Patch CDN Cost} = \text{DAU} \times \text{Patch Size (GB)} \times \$0.04$$

Database & State Persistence Tier Cost

Calculated by measuring database transaction rates per 1,000 active players (DAU) scaled by a genre-specific database persistence factor, combined with a persistent session fee of $\$0.01$ per Peak CCU:

$$\text{Database Cost} = \left(\frac{\text{DAU}}{1000} \times \text{DB Factor} \times 0.12\right) + (\text{Peak CCU} \times 0.01)$$
